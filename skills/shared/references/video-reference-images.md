# 视频参考图规范（折展 / 移动场景）

> 适用：所有用参考图生成视频的技能——`koubo` / `kefu` / `sanguo` / `fuke`，以及底层生成层
> `autodl-h3-video` / `ai-video-gen` / `video-production` 等。**这是硬性要求**（2026-10-03 用户定）。

单图参考时，模型会自行想象产品机构与角度，容易出现**折叠结构失真、细节丢失、人物/产品跨段不一致**。
以下场景必须用**两张**参考图，把两端状态 / 多角度真值交给模型。

## 必须用两张图的场景

| 场景 | 必须提供的两张参考图 | 目的 |
|------|----------------------|------|
| **折叠动作**（展开 → 折叠） | ① 展开态 ② 折叠态 | 锁定动作起止两端结构，防止模型臆造折叠机构 |
| **展开动作**（折叠 → 展开） | ① 折叠态 ② 展开态 | 同上，两端都要有真值 |
| **移动场景**（推行 / 行走 / 转向 / 上下坡等） | ① 45° 斜侧视角 ② 正侧面视角 | 多角度锁定结构，加深细节、减少形变与失真 |

- **折展的两个方向都要覆盖起止两端状态**，不能只给一端。
- 移动场景的两张图应是**同一台产品 / 同一人物、同一配色**，仅视角不同（45° vs 侧面）。
- **两个方向都要 0.3 秒**：**折叠 → 展开**与**展开 → 折叠**的整个状态切换过程**都只能 0.3 秒**，必须在一气呵成内完成，防止模型在缓慢的中间状态臆造机构、导致失真。提示词 `主体动作` 写明状态起止与「切换全程 0.3 秒内一气呵成」。 [2026-10-03 定；2026-10-09 明确两个方向均 ≤0.3 秒]

## 怎么用

1. 参考图放 `outputs/<topic>/assets/`，在配置里 `refs[]` 列**两张**（或多张）文件名。
2. H3 `multi_image`：多个 `-i` 依次传入，例如

   ```bash
   python skills/openclaw/autodl-h3-video/scripts/h3_video.py -w multi_image \
     --prompt "<六段式单行>" -i outputs/<topic>/assets/展开态.jpg -i outputs/<topic>/assets/折叠态.jpg \
     -r 768p竖 -d 8 -o outputs/<topic>/assets/clip1.mp4
   ```

3. 提示词仍按六段式；`主体动作` 字段写明状态起止与**节奏**，折叠 → 展开、展开 → 折叠两个方向都写成「0.3 秒内一气呵成」，如「0.3 秒内从完全展开快速收拢到折叠形态」。脚本（如 `koubo.py`）会对含折展切换的段自动补写该约束。
   台词 / 字幕**禁用破折号「——」**（H3 会丢弃整句）。
4. 各技能沿用自身既有参数、计费前置与验收流程（以对应 SKILL 为准），本规范只加参考图要求。

## 缺图时

- 先从 `assets/`、产品白底图 / 官方图、既有素材里补；仍缺时向用户索取。
- **不要用单张图硬生**折展 / 移动场景；单图属不合格输入，补齐后再发起计费生成。
